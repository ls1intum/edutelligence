Every normal start prints the same context line, so you can always see how much room the session got — this command just shows it without starting one.

Staying up to date

The wrapper never updates itself. It checks once a day whether Logos serves a newer revision and, if so, says so on the next start along with the one command that replaces it — {{ claudeCodeUpdateCommand() }}. That leaves your key, model and settings untouched, so an update is not a re-setup and you do not need to come back to this page for one.

Remove it again

Deletes the wrapper, the config and the key, and offers to clean up an older Logos block in ~/.claude/settings.json if this page put one there before. Nothing of it is left afterwards:
