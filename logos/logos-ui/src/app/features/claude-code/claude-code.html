This replaces your claude.ai login for every Claude Code session on this machine, not just this project: prompts go to Logos, and your subscription is not used. Run /status to see which credential is active, or remove the env block to switch back.

b. Restart Claude Code

Environment variables are read at startup, so exit any running session first. If one was already logged in to claude.ai, run /logout so only the Logos credential remains.

c. Verify

Run claude and type /status: it shows the base URL and the credential source. It should name this Logos instance, not api.anthropic.com.
