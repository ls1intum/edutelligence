# Iris benchmark baseline — 2026-07-21

This baseline from the simplified benchmark used the current `origin/main` Iris
source at commit `98069a3a`, the 50 checked-in scenarios, one trial per scenario,
and the real Iris pipeline. No Iris production source was changed on this
branch. The GPT-5.6 runs omitted both reasoning effort and reasoning mode, so the
provider selected its defaults. After the initial run, all saved answers were
rejudged without invoking the candidates again. The corrected judge context
contains the exact rendered Iris instructions and production-derived mastery
metrics that were available to the candidate.

original candidate usage plus the replacement judge calls. The intervals
describe variation across this scenario set; because this is one candidate
trial, they are not run-to-run stability intervals.

## Evaluator correction

The first judgment pass produced false positives because it saw raw progress and
confidence but not the mastery values produced by Iris's tool, and it did not see
the production prompt's 70% near-deadline policy. The harness now renders the
same production instructions and calculates mastery with Iris's own
`get_mastery` function. Rejudging the saved answers reduced the critical-error
rates from 6/22/14/16/16% to 4/6/4/10/2%, respectively.

The corrected results do **not** show that a more intelligent model has a higher
critical-error rate. Sol has the highest IrisScore and ties mini at 4%; Luna has
the lowest critical-error rate. The overall score differences remain small and
the intervals overlap widely, so this one run also does not establish a stable
model ranking.

## What the baseline exposed

The benchmark surfaced current behavior; it did not alter it or convert these
observations into hard-coded rules.

- Both models had an execution error in the single-MCQ scenario because the
  current pipeline passed a non-text message content object.
- `gpt-5.4-mini` also had an execution error in the German three-MCQ scenario
  caused by malformed JSON in the production path.
- `gpt-5.5` also had an execution error in the solution-injection programming
  scenario because Azure content filtering rejected the prompt.
- All three GPT-5.6 models hit the same two production-path errors as GPT-5.5:
  the single-MCQ message-content mismatch and the Azure-filtered solution-
  injection scenario.
- The independent judge marked unsupported student/course or lecture facts as
  critical incidents. After the evaluator correction, the remaining incidents
  concern genuinely unavailable feedback, unrelated disclosure of learner
  metrics, or claims attributed to lecture sources that do not contain them.

The full machine-readable report and raw worker outputs are kept locally under
the ignored `qa-results/` directory. They are intentionally not committed.
