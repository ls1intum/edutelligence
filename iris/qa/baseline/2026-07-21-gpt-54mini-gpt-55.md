# Iris benchmark baseline — 2026-07-21

This baseline from the simplified benchmark used the current `origin/main` Iris
source at commit `98069a3a`, the 50 checked-in scenarios, one trial per scenario,
and the real Iris pipeline. No Iris production source was changed on this
branch. The GPT-5.6 runs omitted both reasoning effort and reasoning mode, so the
provider selected its defaults.

Total measured model cost for the five full runs was $9.0170, including the
independent judge calls. The intervals describe variation across this scenario
set; because this is one trial, they are not run-to-run stability intervals.

## Important interpretation caveat

The critical-error column is provisional. Auditing the judge evidence after the
run exposed false positives: Iris's production competency tool derives mastery
as `round(progress * confidence)`, correctly producing 36% and 11% from the
fixture data, while the judge only saw the raw inputs and called those values
invented. The judge also called the production prompt's 70% near-deadline policy
unsupported because that policy was not in its evidence packet. Some IrisScores
were reduced for the same reason.

The present results therefore do **not** establish that a more intelligent model
has a higher factual-safety failure rate. In fact, Sol's provisional rate (14%)
is lower than GPT-5.5's (22%), while Terra and Luna are both 16%. Before using
this column to rank models, the benchmark should expose the actual derived tool
facts and relevant production policy to the judge, then rejudge the saved raw
answers without rerunning the candidates.

## What the baseline exposed

The benchmark surfaced current behavior; it did not alter it or convert these
observations into hard-coded rules.

- Both models had an execution error in the single-MCQ scenario because the
  current pipeline passed a non-text message content object.
- `gpt-5.4-mini` also had an execution error in the German three-MCQ scenario
  caused by malformed JSON in the production path.
- `gpt-5.5` also had an execution error in the solution-injection programming
  scenario because Azure content filtering rejected the prompt.
- All three GPT-5.6 models hit the same two production-path errors as GPT-5.5:
  the single-MCQ message-content mismatch and the Azure-filtered solution-
  injection scenario.
- The independent judge marked unsupported student/course or lecture facts as
  critical incidents. The separate critical-error rate makes those visible
  even when the overall IrisScore remains high, subject to the evidence caveat
  above.

The full machine-readable report and raw worker outputs are kept locally under
the ignored `qa-results/` directory. They are intentionally not committed.
